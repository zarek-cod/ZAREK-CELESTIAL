# Plan de Divine Crown

Alcance autorizado: solo la corona, primer accesorio del orden actualizado por el usuario. Los identificadores originales del inventario se conservan; corona es ID 02 en ese paquete.

1. Analizar referencia definitiva y recortes.
2. Consultar especificaciones oficiales y usar maniquí Classic R15.
3. Modelar corona angular: banda negra, doce agujas, gemas facetadas, engastes de plata, nervaduras, remaches y Z posterior.
4. Guardar maestro editable y optimizado, una malla / un material / un UV.
5. Hornear PBR y normal de maestro; limitar a 4000 triángulos.
6. Exportar FBX y GLB; reimportar y comprobar geometría, UV y escala.
7. Renderizar vistas, ajuste R15 y comparación de silueta; iterar.
8. Importar localmente en Studio si el control de aplicaciones concede acceso; no subir a Roblox ni gastar.
9. Documentar resultados ejecutados, publicar rama privada y PR en borrador; detenerse.

Criterio de revisión: conservar gemas y puntas como volúmenes 3D. El halo y el pelo solo se consideran como espacio de diseño; no se desarrollan.
